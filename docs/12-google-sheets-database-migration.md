# Перенос хранилища в Google Sheets

## Что нужно создать вручную

Нужна одна новая пустая Google-таблица в корпоративном аккаунте. Вручную создавать листы, столбцы, формулы или проверки не нужно. Таблицу надо открыть для сервисного аккаунта MegaBot с правом `Редактор`, затем передать разработчику только spreadsheet ID из URL.

Рабочую таблицу доступности с листом `ОСНОВА` смешивать с базой не следует: расписание остаётся удобным пользовательским интерфейсом, а новая таблица становится отдельным структурированным хранилищем.

## Целевая структура

Инициализатор создаст листы:

- `meta` — версия схемы, время последней миграции и контрольные суммы;
- `events` — мероприятия, статус, даты, описание, автор создания;
- `users` — участники, Telegram identity, роли, факультеты и компетенции;
- `availability` — недельные слоты и недоступные дни;
- `meetings` — встречи, состав приглашённых и RSVP;
- `tasks` — основные поля задач и `event_id`;
- `task_assignees` — связь задач с несколькими исполнителями;
- `task_comments` — двусторонние комментарии и комментарии завершения;
- `task_reminders` — правила и состояние отправки напоминаний;
- `bot_messages` — только нужная внутренняя история доставки;
- `settings` — настройки приложения;
- `audit_log` — неизменяемый журнал важных операций.

Каждая строка получает стабильный ID. Связи используют ID, а не отображаемые имена. `event_id` позволяет хранить много одновременных мероприятий и фильтровать задачи без создания отдельного листа на каждое мероприятие.

## Порядок безопасного переключения

1. Создать структуру в пустой таблице и записать версию схемы.
2. Сделать резервную копию `/opt/megabot/database.json`.
3. Импортировать JSON в листы без остановки текущего бота.
4. Сверить количество пользователей, мероприятий, задач, назначений, комментариев, встреч и слотов.
5. Включить временный dual-write: JSON и Google Sheets получают одни и те же изменения.
6. Выполнить roundtrip и сценарные тесты, сравнить контрольные суммы.
7. Переключить чтение на Google Sheets, сохранив JSON как аварийный снимок.
8. После стабильного периода отключить запись в JSON, но не удалять резервную копию.

Пустая таблица не должна становиться production-источником до успешного импорта и сверки. Секрет сервисного аккаунта хранится только на Selectel и не записывается в Git.
