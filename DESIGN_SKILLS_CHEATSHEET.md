# Шпаргалка по дизайн-скиллам

Все три скилла установлены локально в `.agents/skills/`. Если новый скилл не появился в автодополнении Codex, перезапусти Codex.

## Taste Skill (`$design-taste-frontend`)

Используй для выбора общего дизайн-направления и защиты от шаблонного, безликого интерфейса.

Базовый запрос:

```text
Используй $design-taste-frontend.

Задача: редизайн существующего Telegram Mini App.
DESIGN_VARIANCE=4
MOTION_INTENSITY=4
VISUAL_DENSITY=7

Сохрани функции, реальные тексты и пользовательские сценарии.
Фирменные материалы имеют абсолютный приоритет.
Сначала проведи аудит существующего интерфейса, затем внеси изменения.
```

Настройки:

- `DESIGN_VARIANCE` определяет свободу композиции: `1` означает строгую симметрию, `10` означает смелую асимметрию.
- `MOTION_INTENSITY` определяет интенсивность анимаций: `1` означает почти статичный интерфейс, `10` означает сложную постановочную анимацию.
- `VISUAL_DENSITY` определяет плотность: `1` означает много воздуха, `10` означает компактный рабочий интерфейс.

Для существующего продукта всегда проси сначала провести аудит и сохранить текущие сценарии. Прикладывай ссылку на Figma, логотипы, шрифты, палитру и примеры фирменных носителей.

## UI/UX Pro Max (`$ui-ux-pro-max`)

Используй для исследования UX-паттернов, доступности, иконок, анимаций, цветовых решений и рекомендаций для конкретного стека.

Создать и сохранить отчёт по дизайн-системе:

```powershell
py .agents\skills\ui-ux-pro-max\scripts\search.py "<продукт + аудитория + характер>" --design-system --persist --output-dir "." -p "<название проекта>" --variance 4 --motion 4 --density 7 -f markdown
```

Пересоздать существующий отчёт:

```powershell
py .agents\skills\ui-ux-pro-max\scripts\search.py "<запрос>" --design-system --persist --force --output-dir "." -p "<название проекта>"
```

Точечные исследования:

```powershell
py .agents\skills\ui-ux-pro-max\scripts\search.py "<запрос>" --domain ux -n 10
py .agents\skills\ui-ux-pro-max\scripts\search.py "<запрос>" --domain icons -n 10
py .agents\skills\ui-ux-pro-max\scripts\search.py "<запрос>" --domain typography -n 10
py .agents\skills\ui-ux-pro-max\scripts\search.py "<запрос>" --domain color -n 10
py .agents\skills\ui-ux-pro-max\scripts\search.py "<запрос>" --domain gsap -n 10
py .agents\skills\ui-ux-pro-max\scripts\search.py "<запрос>" --stack react -n 10
```

Основные области поиска:

- `product` - тип продукта;
- `style` - визуальный стиль;
- `color` - палитры;
- `typography` - шрифтовые пары;
- `ux` - UX-рекомендации;
- `icons` - иконки;
- `gsap` - анимационные паттерны;
- `chart` - графики;
- `landing` - посадочные страницы;
- `react` и `web` - рекомендации для стека.

Результаты базы являются исследовательской подсказкой, а не главным источником истины. Реальный продукт и фирменные материалы всегда важнее.

## Impeccable (`$impeccable`)

Используй для фиксации контекста продукта, критики интерфейса, системной доработки и финальной проверки.

Загрузить контекст продукта:

```powershell
node .agents\skills\impeccable\scripts\context.mjs --target src\components\MiniApp.tsx
```

Запустить детектор после завершения интерфейса:

```powershell
node .agents\skills\impeccable\scripts\detect.mjs --json src\App.tsx src\components\MiniApp.tsx src\index.css
```

Полезные команды в запросах:

- `audit` или `critique` - найти UX- и визуальные проблемы без изменения кода;
- `bolder` - сделать существующий дизайн смелее в рамках текущего фирстиля;
- `clarify` - улучшить иерархию и понятность;
- `distill` - убрать лишнюю визуальную сложность;
- `layout` - исправить композицию, интервалы и ритм;
- `typeset` - привести в порядок типографику;
- `colorize` - системно добавить цвет;
- `polish` - отполировать интервалы, шрифты, цвета и состояния;
- `harden` - проверить адаптивность, ошибки, загрузку и пустые состояния;
- `animate` - добавить осмысленную анимацию;
- `adapt` - адаптировать экран для другого размера или платформы;
- `live` - интерактивно подбирать варианты элементов в браузере.

`PRODUCT.md` хранит факты о продукте и ограничениях. `DESIGN.md` хранит принятую дизайн-систему. Не обновляй их на основании случайной идеи до проверки реального интерфейса.

## Рекомендуемый совместный процесс

1. Taste Skill выбирает и фиксирует направление.
2. UI/UX Pro Max исследует паттерны и проверяет UX, доступность и технические решения.
3. Impeccable загружает контекст продукта, помогает реализовать изменения и проводит детектор.
4. Выполняются `npm run lint` и `npm run build`.
5. Интерфейс проверяется на ширине 375 пикселей, в горизонтальной ориентации, в светлой и тёмной теме, а также с отключёнными анимациями.

## Короткий универсальный запрос

```text
Используй $design-taste-frontend, $ui-ux-pro-max и $impeccable.

Сначала изучи PRODUCT.md, DESIGN.md и существующий интерфейс.
Сохрани функции, реальные тексты, права пользователей и сценарии.
Фирменные материалы имеют абсолютный приоритет.

DESIGN_VARIANCE=4
MOTION_INTENSITY=4
VISUAL_DENSITY=7

Проведи аудит, предложи направление, реализуй изменения,
проверь светлую и тёмную темы, мобильные safe-area,
затем запусти детектор, lint и production-сборку.
```

## Дополнение для Telegram-сценариев — 2026-08-03

Дизайн-аудит чатового интерфейса должен проверять не только внешний вид, но и устойчивость состояния:

- одна операция проходит в одном редактируемом сообщении;
- выбранные значения видны числом, а не только цветом;
- массовое действие находится рядом с частными действиями;
- после сохранения есть явное подтверждение и следующий шаг;
- переход по `t.me` не уничтожает состояние Mini App;
- loading, retry и synchronization status входят в макет до реализации.

В запрос на полировку Telegram UI добавлять: «проверь сценарий с уникальными message ID, повторным открытием, временной потерей Google Sheets и возвратом из профиля участника».

## Дополнение 2026-08-09

- Для обрезки изображений один и тот же pure helper вычисляет source rectangle для preview и export; отдельно проверяются четыре угла, центр и zoom.
- Для отменяемого редактора сначала фиксируется baseline, затем меняется draft; cancel восстанавливает baseline, save фиксирует draft.
- Для Telegram не смешивать `Назад` из reply-клавиатуры с inline-`Назад`. Это обязательная проверка перед релизом.
- Для раскрывающихся длинных списков начальное состояние закрыто, кнопка имеет `aria-expanded`, элементы управления не меньше 44 px.
