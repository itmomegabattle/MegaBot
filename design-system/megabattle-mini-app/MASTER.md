# MegaBattle Mini App — мастер-система интерфейса

> Это основной источник правил для интерфейса. Фирменные материалы из Figma «Megabattle 2025–2026» имеют приоритет над универсальными рекомендациями дизайн-скиллов.

## Позиционирование

- **Тип продукта:** внутренняя мобильная операционная система команды.
- **Подтипы:** event management, calendar & scheduling, task management, team directory.
- **Контекст:** частое короткое использование внутри Telegram, преимущественно одной рукой.
- **Стиль:** `Live Control Deck` — плотный, быстрый и функциональный интерфейс с фирменной сценической энергией MegaBattle.
- **Параметры:** `VARIANCE=4`, `MOTION=4`, `DENSITY=7`.

## Визуальная система

### Цвета

| Назначение | Светлая тема | Тёмная тема |
|---|---|---|
| Основной фон | `#F3F6F8` | `#000000` |
| Поверхность | `#FFFFFF` | `#0D1117` |
| Вторичная поверхность | `#EAF2FB` | `#101D2B` |
| Контрол | `#F4F7FA` | `#151B23` |
| Основной текст | `#061222` | `#FFFFFF` |
| Вторичный текст | `#4D647A` | `#C1CCD8` |
| Primary / CTA | `#0069E0` | `#0069E0` |
| Hover | `#1677E8` | `#1677E8` |
| Active | `#0058BD` | `#0058BD` |

Фирменные дополнительные цвета: `#2685BB`, `#BB2626`, `#60309C`, `#9D005F`. Они предназначены для дозированного использования в декоративных лентах, факультетских и смысловых акцентах — не как случайная раскраска карточек.

Семантические цвета не заменяют бренд:

- успех `#059669`;
- внимание `#D97706`;
- критическая ошибка `#E11D48`.

Статус никогда не передаётся только цветом: рядом нужен текст или иконка.

### Типографика

- **Druk Text Wide Cyr:** название экрана, крупные акцентные заголовки, фирменные цифры.
- **Raleway:** весь интерфейс, формы, подписи, таблицы и кнопки.
- Поля ввода и списки на телефоне — минимум `16px`, чтобы iOS не увеличивала страницу.
- Минимальный полезный размер вспомогательного текста — `12px`.
- Не использовать Calistoga, Inter, системный sans или декоративные шрифты как замену фирменным.

### Иконки

- Единая библиотека: **Phosphor Icons**.
- Базовый стиль: `regular`; активная навигация и ключевой статус: `fill` или `duotone`.
- Размеры: `16px` внутри компактной кнопки, `20px` для навигации и обычных действий, `24px` для пустых состояний.
- Не использовать emoji и самодельные SVG вместо иконок интерфейса.

## Компоновка

- Максимальная ширина приложения: `768px`.
- Базовый горизонтальный отступ: `16px`; внутренний отступ карточки: `16px`.
- Вертикальный ритм: `4 / 8 / 12 / 16 / 24px`.
- Минимальная зона нажатия: `44×44px`.
- Нижняя навигация: максимум 5 разделов, фиксирована с учётом Telegram safe area.
- Главная кнопка текущего сценария может быть sticky над навигацией, но не должна перекрывать контент.
- Плотные данные показываются списками и таблицами; подробности раскрываются по запросу.

## Компоненты и состояния

- **Primary:** сплошной MegaBattle Blue, белая иконка и подпись.
- **Secondary:** спокойная поверхность, синяя подпись; не конкурирует с primary.
- **Destructive:** красный только для подтверждённого опасного действия.
- **Карточка:** радиус `20–24px`, тонкая граница, один уровень мягкой тени.
- **Форма:** подпись всегда видима; placeholder не заменяет label.
- **Загрузка:** локальный индикатор в месте действия; skeleton для ожидания дольше 300 мс.
- **Ошибка:** рядом с проблемным блоком, `role="alert"`, понятное действие для восстановления.
- **Пустое состояние:** что произошло, зачем раздел нужен, что можно сделать дальше.

## Движение

- Длительность переходов `150–240ms`.
- Анимация объясняет смену состояния, а не украшает экран.
- Нажатие допускает лёгкий scale/translate; никакого постоянного движения у рабочих карточек.
- Обязательно учитывать `prefers-reduced-motion`.

## Запрещено

- generic SaaS / luxury / glassmorphism как основа интерфейса;
- градиенты и свечение на каждом блоке;
- несколько библиотек иконок;
- светлая карточка без переопределения в тёмной теме;
- мелкие кликабельные подписи;
- скрытые горизонтальные скроллы для главных действий;
- изменение реальных текстов, ролей и сценариев ради макета.

## Контроль перед выпуском

- проверить все 5 разделов в светлой и тёмной темах;
- проверить ширины `375px`, `768px` и landscape;
- убедиться, что клавиатура не закрывает активное поле;
- проверить safe area, sticky-кнопки и нижнюю навигацию;
- пройти keyboard focus, контраст, loading/error/empty/disabled состояния;
- прогнать lint, production build и ручной smoke test.
