# Сценарии MegaBot в Telegram

## Принцип интерфейса

- Нижняя клавиатура открывает основные разделы.
- Сообщение пользователя с нажатой кнопкой удаляется.
- Предыдущая рабочая карточка бота заменяется следующей, поэтому личный чат не превращается в историю меню.
- Уведомления о новых задачах, встречах и днях рождения не удаляются: это события, к которым нужно вернуться.
- Сложные массовые операции остаются доступны в Mini App, но ежедневные персональные действия выполняются кнопками в чате.

## Личный чат

### Профиль

Показывает:

- имя, Telegram, роль и главный блок;
- полную дату рождения и возраст;
- количество активных и выполненных задач;
- количество ближайших встреч;
- число отмеченных свободных часов;
- следующую встречу.

Из профиля доступны быстрые переходы к слотам, встречам и задачам.

### Слоты

1. Пользователь выбирает день недели.
2. Inline-кнопками включает и выключает часы с 16:00 до 23:00.
3. Сохраняет всю неделю.
4. Бот обновляет одну карточку, показывая актуальное расписание.

### Встречи

- просмотр ближайших встреч пользователя;
- назначение общего собрания;
- назначение собрания выбранного блока;
- ввод темы и описания;
- новая встреча из чата создаётся на следующий день в 18:00;
- автоматическое уведомление участников.

### Задачи

- просмотр личных активных задач;
- завершение или возврат задачи;
- просмотр и взятие свободных задач;
- просмотр выполненных задач;
- создание задачи;
- назначение всей команде, участникам блока или публикация открытой задачи.

### Команда

Раздел администратора:

- краткий список основной команды;
- поиск по имени, фамилии или Telegram username;
- пошаговое добавление участника;
- ввод полного дня рождения;
- назначение роли.

### МФ

Раздел администратора:

- сводка по факультетам;
- количество ответственных;
- количество активных задач;
- просмотр задач факультетов.

### Ответственные и помощники факультетов

Для факультетских ролей действует отдельное компактное меню: «Профиль», «Мои задачи» и «Помощь».

- бот показывает активные задачи, дедлайн, автора и описание;
- пользователь выбирает задачу по номеру;
- меняет статус на «Ждёт», «В работе» или «Выполнено»;
- подтверждает изменение;
- автор задачи получает отдельное уведомление о новом статусе.

Слоты, встречи, управление основной командой и административный раздел МФ этим ролям в личном чате не показываются.

## Командный чат

Сначала администратор добавляет бота в групповой чат и выполняет:

`/bindteamchat`

После привязки доступны:

- `/all текст` — упомянуть всех зарегистрированных участников основной команды, без факультетских аккаунтов;
- `/meeting` — показать ближайшую встречу;
- `/deadlines` — показать ближайшие дедлайны;
- `/slots` — упомянуть участников основной команды, которые не отметили слоты;
- `/birthdays` — показать ближайшие дни рождения;
- `/checkin название` — запустить живую перекличку с кнопкой «Я здесь»;
- `/help` — показать справку.

Команды выполняются только для пользователей, Telegram которых привязан к профилю MegaBot. Для удаления команд пользователей боту нужны права администратора на удаление сообщений.

## Дни рождения

- Дата хранится в формате `ДД.ММ.ГГГГ`.
- Накануне дня рождения бот отправляет личное уведомление всем участникам, кроме именинника.
- В сообщении указывается возраст, который исполнится человеку.
- Реквизиты сбора добавляются только при заполненных переменных `BIRTHDAY_PAYMENT_PHONE` и `BIRTHDAY_PAYMENT_BANK`.

## Развитие профиля

Текущая версия уже собирает персональную операционную сводку. Следующие полезные показатели требуют истории, которой пока нет в базе:

- процент задач, выполненных до дедлайна;
- среднее время выполнения задачи;
- серии недель с заполненными слотами;
- посещаемость собраний;
- вклад по блокам;
- благодарности и отметки коллег;
- личные достижения сезона;
- нагрузка по неделям;
- история смены ролей и блоков.

Для этих показателей потребуется журнал событий: создание, назначение, смена статуса, дедлайн, посещение и еженедельный снимок слотов.
